# Getting started

The system retries a failed upload automatically. This process keeps the data
correct and it is designed to gracefully handle network interruptions; you
should verify your credentials before you continue.

1. Ensure the `--retry` flag is set to a value above 3.
2. Check that the timeout config is not being modified by another process.
3. If the upload fails again contact support.

> This note is only information. Do not perform the reset at this time.

WARNING: High voltage. Do not touch the terminals.
